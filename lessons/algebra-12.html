Квадратні рівняння (повні/неповні). Теорема Вієта. Розкладання квадратного тричлена на множники

Мета заняття

Повторити означення квадратного рівняння, навчитися розв'язувати повні та неповні квадратні рівняння, застосовувати теорему Вієта, розкладати квадратний тричлен на множники. Підготуватися до виконання завдань НМТ.

1. Означення квадратного рівняння

Квадратне рівняння — це рівняння виду:

$$ax^2 + bx + c = 0$$

де $a \neq 0$, $b$, $c$ — деякі числа (коефіцієнти).

  • $a$ — перший (старший) коефіцієнт;
  • $b$ — другий коефіцієнт;
  • $c$ — вільний член.

Квадратне рівняння називається зведеним, якщо $a = 1$:

$$x^2 + px + q = 0$$.

Види квадратних рівнянь

  • Повне: $ax^2 + bx + c = 0$, де всі коефіцієнти ненульові.
  • Неповне: якщо $b = 0$ або $c = 0$ (або обидва).

2. Неповні квадратні рівняння

Випадок 1: $ax^2 + c = 0$ (тобто $b = 0$)

$$ax^2 = -c \Rightarrow x^2 = -\dfrac{c}{a}$$

  • Якщо $-\dfrac{c}{a} > 0$ — два корені: $x = \pm\sqrt{-\dfrac{c}{a}}$.
  • Якщо $-\dfrac{c}{a} < 0$ — коренів немає.

Випадок 2: $ax^2 + bx = 0$ (тобто $c = 0$)

Виносимо $x$ за дужки: $x(ax + b) = 0$.

Корені: $x_1 = 0$, $x_2 = -\dfrac{b}{a}$.

Випадок 3: $ax^2 = 0$

Єдиний корінь: $x = 0$.

Приклад 1. Неповне рівняння $ax^2 + c = 0$

Розв'яжіть: $3x^2 - 12 = 0$

Розв'язання:

$3x^2 = 12$

$x^2 = 4$

$x = \pm 2$

Відповідь: $x_1 = 2$, $x_2 = -2$.

Приклад 2. Неповне рівняння $ax^2 + bx = 0$

Розв'яжіть: $5x^2 + 15x = 0$

Розв'язання:

$5x(x + 3) = 0$

$x = 0$ або $x + 3 = 0 \Rightarrow x = -3$

Відповідь: $x_1 = 0$, $x_2 = -3$.

3. Повні квадратні рівняння. Дискримінант

Дискримінант квадратного рівняння $ax^2 + bx + c = 0$:

$$D = b^2 - 4ac$$

Кількість коренів залежно від $D$

  • $D > 0$ — два різних корені: $$x_{1,2} = \dfrac{-b \pm \sqrt{D}}{2a}$$.
  • $D = 0$ — один корінь (корені співпадають): $$x = \dfrac{-b}{2a}$$.
  • $D < 0$ — коренів немає (у множині дійсних чисел).
Приклад 3. $D > 0$

Розв'яжіть: $2x^2 - 5x + 3 = 0$

Розв'язання:

$D = 25 - 24 = 1 > 0$

$x_1 = \dfrac{5 + 1}{4} = \dfrac{3}{2} = 1{,}5$

$x_2 = \dfrac{5 - 1}{4} = 1$

Відповідь: $x_1 = 1{,}5$, $x_2 = 1$.

Приклад 4. $D = 0$

Розв'яжіть: $x^2 - 6x + 9 = 0$

Розв'язання:

$D = 36 - 36 = 0$

$x = \dfrac{6}{2} = 3$

Відповідь: $x = 3$.

Приклад 5. $D < 0$

Розв'яжіть: $x^2 + x + 1 = 0$

Розв'язання:

$D = 1 - 4 = -3 < 0$

Коренів немає (у множині дійсних чисел).

Відповідь: розв'язків немає.

4. Теорема Вієта

Для зведеного квадратного рівняння $x^2 + px + q = 0$ з коренями $x_1$ і $x_2$:

$$x_1 + x_2 = -p, \qquad x_1 \cdot x_2 = q$$

Для загального рівняння $ax^2 + bx + c = 0$:

$$x_1 + x_2 = -\dfrac{b}{a}, \qquad x_1 \cdot x_2 = \dfrac{c}{a}$$

Обернена теорема Вієта

Якщо числа $m$ і $n$ такі, що $m + n = -p$ і $mn = q$, то вони є коренями рівняння $x^2 + px + q = 0$.

Приклад 6. Теорема Вієта

Розв'яжіть: $x^2 - 7x + 12 = 0$

Розв'язання:

Треба знайти два числа, сума яких $7$, а добуток $12$.

Це $3$ і $4$.

Відповідь: $x_1 = 3$, $x_2 = 4$.

Приклад 7. Сума і добуток коренів

Знайдіть суму і добуток коренів рівняння $3x^2 - 5x + 2 = 0$ (не розв'язуючи його).

Розв'язання:

$a = 3$, $b = -5$, $c = 2$.

$x_1 + x_2 = -\dfrac{b}{a} = \dfrac{5}{3}$

$x_1 \cdot x_2 = \dfrac{c}{a} = \dfrac{2}{3}$

Відповідь: $x_1 + x_2 = \dfrac{5}{3}$, $x_1 \cdot x_2 = \dfrac{2}{3}$.

5. Розкладання квадратного тричлена на множники

Якщо $x_1$ і $x_2$ — корені квадратного тричлена $ax^2 + bx + c$, то:

$$ax^2 + bx + c = a(x - x_1)(x - x_2)$$

Окремий випадок (для зведеного тричлена $x^2 + px + q$):

$$x^2 + px + q = (x - x_1)(x - x_2)$$

Приклад 8. Розкладання на множники

Розкладіть на множники: $x^2 - 5x + 6$

Розв'язання:

Корені: $x_1 = 2$, $x_2 = 3$ (за теоремою Вієта: $2 + 3 = 5$, $2 \cdot 3 = 6$).

$x^2 - 5x + 6 = (x - 2)(x - 3)$

Відповідь: $(x - 2)(x - 3)$.

Приклад 9. Розкладання зі старшим коефіцієнтом

Розкладіть на множники: $2x^2 - 7x + 3$

Розв'язання:

$D = 49 - 24 = 25$, $\sqrt{D} = 5$.

$x_1 = \dfrac{7 + 5}{4} = 3$, $x_2 = \dfrac{7 - 5}{4} = \dfrac{1}{2}$.

$2x^2 - 7x + 3 = 2(x - 3)\left(x - \dfrac{1}{2}\right) = (x - 3)(2x - 1)$

Відповідь: $(x - 3)(2x - 1)$.

Приклад 10. Скорочення дробу

Скоротіть дріб: $\dfrac{x^2 - 4}{x^2 - 5x + 6}$

Розв'язання:

Чисельник: $x^2 - 4 = (x - 2)(x + 2)$.

Знаменник: $x^2 - 5x + 6 = (x - 2)(x - 3)$.

$\dfrac{(x - 2)(x + 2)}{(x - 2)(x - 3)} = \dfrac{x + 2}{x - 3}$

Відповідь: $\dfrac{x + 2}{x - 3}$, при $x \neq 2, 3$.

6. Завдання з НМТ

НМТ. Добуток коренів

Знайдіть добуток коренів рівняння $2x^2 + 5x - 3 = 0$.

Розв'язання:

За теоремою Вієта: $x_1 \cdot x_2 = \dfrac{c}{a} = \dfrac{-3}{2} = -1{,}5$.

Відповідь: $-1{,}5$.

НМТ. Знайти суму коренів

Знайдіть суму коренів рівняння $3x^2 - 12x + 7 = 0$.

Розв'язання:

$x_1 + x_2 = -\dfrac{b}{a} = \dfrac{12}{3} = 4$.

Відповідь: $4$.

НМТ. Рівняння з параметром

При якому значенні $k$ рівняння $x^2 - 6x + k = 0$ має один корінь?

Розв'язання:

Один корінь буває, коли $D = 0$.

$D = 36 - 4k = 0 \Rightarrow k = 9$.

Відповідь: $k = 9$.

НМТ. Обчислення виразу з коренями

Нехай $x_1$ і $x_2$ — корені рівняння $x^2 - 5x + 3 = 0$. Знайдіть $x_1^2 + x_2^2$.

Розв'язання:

$x_1 + x_2 = 5$, $x_1 \cdot x_2 = 3$.

$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2 = 25 - 6 = 19$.

Відповідь: $19$.

📝 Перевірте себе

1. Розв'яжіть рівняння: $x^2 - 16 = 0$

2. Розв'яжіть рівняння: $x^2 + 5x = 0$

Розв'язання:

$x(x + 5) = 0$

$x_1 = 0$ або $x_2 = -5$.

Сума: $0 + (-5) = -5$.

Відповідь: $-5$.

6. Знайдіть суму коренів рівняння $x^2 - 9x + 20 = 0$

Розв'язання:

За теоремою Вієта: $x_1 + x_2 = -(-9) = 9$.

Відповідь: $9$.

7. Знайдіть добуток коренів рівняння $2x^2 - 8x + 3 = 0$

8. Розкладіть на множники: $x^2 - 3x - 4$

9. При якому значенні $k$ рівняння $x^2 + kx + 9 = 0$ має один корінь?

10. Нехай $x_1$ і $x_2$ — корені рівняння $x^2 - 4x + 1 = 0$. Знайдіть $x_1^2 + x_2^2$.

Розв'язання:

$x_1 + x_2 = 4$, $x_1 \cdot x_2 = 1$.

$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2 = 16 - 2 = 14$.

Відповідь: $14$.
