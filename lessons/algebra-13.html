Рівняння, що зводяться до квадратних. Біквадратні рівняння

Мета заняття

Навчитися розв'язувати рівняння, що зводяться до квадратних, методом заміни змінної. Опанувати біквадратні рівняння, дробово-раціональні та ірраціональні рівняння, що зводяться до квадратних. Підготуватися до виконання завдань НМТ.

1. Ідея методу заміни змінної

Багато рівнянь вищого степеня можна звести до квадратного, якщо ввести нову змінну. Ідея методу:

  1. Помітити в рівнянні повторюваний вираз (або степінь змінної).
  2. Позначити цей вираз новою змінною $t$.
  3. Отримати квадратне рівняння відносно $t$.
  4. Розв'язати його та повернутися до початкової змінної.

Головне правило: після знаходження $t$ обов'язково повертаємося до $x$ і перевіряємо, чи задовольняють корені початкове рівняння.

2. Біквадратні рівняння

Біквадратне рівняння — це рівняння виду:

$$ax^4 + bx^2 + c = 0, \quad a \neq 0$$

Алгоритм розв'язування

  1. Заміна: $t = x^2$, причому $t \geq 0$.
  2. Отримуємо квадратне рівняння: $at^2 + bt + c = 0$.
  3. Знаходимо корені $t_1$, $t_2$.
  4. Відкидаємо від'ємні значення $t$ (бо $x^2 \geq 0$).
  5. Для кожного додатного $t$: $x = \pm\sqrt{t}$.
Приклад 1. Біквадратне рівняння (чотири корені)

Розв'яжіть: $x^4 - 5x^2 + 4 = 0$

Розв'язання:

Заміна: $t = x^2$, $t \geq 0$.

$t^2 - 5t + 4 = 0$

За теоремою Вієта: $t_1 = 1$, $t_2 = 4$. Обидва додатні ✅

Повертаємось до $x$:

  • $x^2 = 1 \Rightarrow x = \pm 1$
  • $x^2 = 4 \Rightarrow x = \pm 2$

Відповідь: $x_1 = 1$, $x_2 = -1$, $x_3 = 2$, $x_4 = -2$.

Приклад 2. Біквадратне рівняння (два корені)

Розв'яжіть: $x^4 + 3x^2 - 4 = 0$

Розв'язання:

Заміна: $t = x^2$, $t \geq 0$.

$t^2 + 3t - 4 = 0$

$t_1 = 1$, $t_2 = -4$ (відкидаємо, бо $t < 0$).

$x^2 = 1 \Rightarrow x = \pm 1$

Відповідь: $x_1 = 1$, $x_2 = -1$.

Приклад 3. Біквадратне рівняння з кратним коренем

Розв'яжіть: $x^4 - 6x^2 + 9 = 0$

Розв'язання:

Заміна: $t = x^2$, $t \geq 0$.

$t^2 - 6t + 9 = 0$

$(t - 3)^2 = 0 \Rightarrow t = 3$

$x^2 = 3 \Rightarrow x = \pm\sqrt{3}$

Відповідь: $x_1 = \sqrt{3}$, $x_2 = -\sqrt{3}$.

Приклад 4. Біквадратне рівняння без коренів

Розв'яжіть: $x^4 + 5x^2 + 4 = 0$

Розв'язання:

Заміна: $t = x^2$, $t \geq 0$.

$t^2 + 5t + 4 = 0$

$t_1 = -1$, $t_2 = -4$. Обидва від'ємні — відкидаємо обидва.

Відповідь: розв'язків немає.

3. Рівняння з повторюваним виразом

Часто в рівнянні повторюється цілий вираз, наприклад $(x^2 - 3x)$. Тоді заміна $t = x^2 - 3x$ спрощує рівняння.

Приклад 5. Заміна цілого виразу

Розв'яжіть: $(x^2 - 3x)^2 - 2(x^2 - 3x) - 8 = 0$

Розв'язання:

Заміна: $t = x^2 - 3x$.

$t^2 - 2t - 8 = 0$

$t_1 = 4$, $t_2 = -2$ (за теоремою Вієта).

Повертаємось до $x$:

  • $x^2 - 3x = 4 \Rightarrow x^2 - 3x - 4 = 0 \Rightarrow x_1 = 4$, $x_2 = -1$.
  • $x^2 - 3x = -2 \Rightarrow x^2 - 3x + 2 = 0 \Rightarrow x_3 = 1$, $x_4 = 2$.

Відповідь: $x_1 = 4$, $x_2 = -1$, $x_3 = 1$, $x_4 = 2$.

Приклад 6. Заміна $(x - 1)^2$

Розв'яжіть: $(x^2 - 2x + 1)^2 - 5(x^2 - 2x + 1) + 4 = 0$

Розв'язання:

Помічаємо: $x^2 - 2x + 1 = (x - 1)^2 \geq 0$.

Заміна: $t = (x - 1)^2$, $t \geq 0$.

$t^2 - 5t + 4 = 0 \Rightarrow t_1 = 1$, $t_2 = 4$.

Повертаємось:

  • $(x - 1)^2 = 1 \Rightarrow x - 1 = \pm 1 \Rightarrow x_1 = 2$, $x_2 = 0$.
  • $(x - 1)^2 = 4 \Rightarrow x - 1 = \pm 2 \Rightarrow x_3 = 3$, $x_4 = -1$.

Відповідь: $x_1 = 2$, $x_2 = 0$, $x_3 = 3$, $x_4 = -1$.

4. Дробово-раціональні рівняння, що зводяться до квадратних

Якщо в рівнянні є дроби зі змінною в знаменнику — спочатку знаходимо ОДЗ, а потім вводимо заміну.

Приклад 7. Дробово-раціональне рівняння

Розв'яжіть: $\dfrac{1}{x^2} - \dfrac{3}{x} + 2 = 0$

Розв'язання:

ОДЗ: $x \neq 0$.

Заміна: $t = \dfrac{1}{x}$. Тоді $\dfrac{1}{x^2} = t^2$.

$t^2 - 3t + 2 = 0 \Rightarrow t_1 = 1$, $t_2 = 2$.

Повертаємось:

  • $\dfrac{1}{x} = 1 \Rightarrow x_1 = 1$.
  • $\dfrac{1}{x} = 2 \Rightarrow x_2 = \dfrac{1}{2}$.

Обидва корені входять в ОДЗ ✅

Відповідь: $x_1 = 1$, $x_2 = \dfrac{1}{2}$.

Приклад 8. Симетричне рівняння

Розв'яжіть: $x^2 + \dfrac{1}{x^2} + x + \dfrac{1}{x} = 4$

Розв'язання:

ОДЗ: $x \neq 0$.

Позначимо $t = x + \dfrac{1}{x}$. Тоді:

$$t^2 = x^2 + 2 + \dfrac{1}{x^2} \Rightarrow x^2 + \dfrac{1}{x^2} = t^2 - 2$$

Рівняння набуває вигляду:

$t^2 - 2 + t = 4 \Rightarrow t^2 + t - 6 = 0$

$t_1 = 2$, $t_2 = -3$.

Повертаємось:

  • $x + \dfrac{1}{x} = 2 \Rightarrow x^2 - 2x + 1 = 0 \Rightarrow (x-1)^2 = 0 \Rightarrow x = 1$.
  • $x + \dfrac{1}{x} = -3 \Rightarrow x^2 + 3x + 1 = 0 \Rightarrow x = \dfrac{-3 \pm \sqrt{5}}{2}$.

Відповідь: $x_1 = 1$, $x_{2,3} = \dfrac{-3 \pm \sqrt{5}}{2}$.

5. Ірраціональні рівняння, що зводяться до квадратних

Приклад 9. Рівняння з квадратним коренем

Розв'яжіть: $x + \sqrt{x} - 6 = 0$

Розв'язання:

ОДЗ: $x \geq 0$.

Заміна: $t = \sqrt{x}$, $t \geq 0$. Тоді $x = t^2$.

$t^2 + t - 6 = 0 \Rightarrow t_1 = 2$, $t_2 = -3$ (відкидаємо, бо $t \geq 0$).

$\sqrt{x} = 2 \Rightarrow x = 4$.

Перевірка: $4 + \sqrt{4} - 6 = 4 + 2 - 6 = 0$ ✅

Відповідь: $x = 4$.

Приклад 10. Рівняння з $\sqrt[4]{x}$

Розв'яжіть: $\sqrt{x} - 3\sqrt[4]{x} + 2 = 0$

Розв'язання:

ОДЗ: $x \geq 0$.

Помічаємо: $\sqrt{x} = (\sqrt[4]{x})^2$.

Заміна: $t = \sqrt[4]{x}$, $t \geq 0$.

$t^2 - 3t + 2 = 0 \Rightarrow t_1 = 1$, $t_2 = 2$.

Повертаємось:

  • $\sqrt[4]{x} = 1 \Rightarrow x_1 = 1$.
  • $\sqrt[4]{x} = 2 \Rightarrow x_2 = 2^4 = 16$.

Відповідь: $x_1 = 1$, $x_2 = 16$.

6. Завдання з НМТ

НМТ. Сума коренів біквадратного рівняння

Знайдіть суму коренів рівняння $x^4 - 10x^2 + 9 = 0$.

Розв'язання:

Заміна: $t = x^2$, $t \geq 0$.

$t^2 - 10t + 9 = 0 \Rightarrow t_1 = 1$, $t_2 = 9$.

Корені: $x = \pm 1, \pm 3$.

Сума: $1 + (-1) + 3 + (-3) = 0$.

Відповідь: $0$.

НМТ. Добуток коренів біквадратного рівняння

Знайдіть добуток коренів рівняння $x^4 - 8x^2 + 16 = 0$.

Розв'язання:

Заміна: $t = x^2$, $t \geq 0$.

$t^2 - 8t + 16 = 0 \Rightarrow (t - 4)^2 = 0 \Rightarrow t = 4$.

$x^2 = 4 \Rightarrow x = \pm 2$.

Добуток: $2 \cdot (-2) = -4$.

Відповідь: $-4$.

НМТ. Скільки коренів має рівняння

Скільки дійсних коренів має рівняння $x^4 - 3x^2 - 4 = 0$?

Розв'язання:

Заміна: $t = x^2$, $t \geq 0$.

$t^2 - 3t - 4 = 0 \Rightarrow t_1 = 4$, $t_2 = -1$ (відкидаємо).

$x^2 = 4 \Rightarrow x = \pm 2$ — два корені.

Відповідь: $2$.

НМТ. Рівняння з повторюваним виразом

Розв'яжіть рівняння $(x^2 + x - 1)(x^2 + x + 2) = 40$.

Розв'язання:

Заміна: $t = x^2 + x$. Тоді:

$(t - 1)(t + 2) = 40$

$t^2 + t - 2 = 40$

$t^2 + t - 42 = 0$

$t_1 = 6$, $t_2 = -7$.

Повертаємось:

  • $x^2 + x = 6 \Rightarrow x^2 + x - 6 = 0 \Rightarrow x_1 = 2$, $x_2 = -3$.
  • $x^2 + x = -7 \Rightarrow x^2 + x + 7 = 0 \Rightarrow D = -27 < 0$, коренів немає.

Відповідь: $x_1 = 2$, $x_2 = -3$.

📝 Перевірте себе

1. Розв'яжіть рівняння: $x^4 - 5x^2 + 4 = 0$

2. Розв'яжіть рівняння: $x^4 + 4x^2 - 5 = 0$. Скільки коренів має рівняння?

Розв'язання:

Заміна: $t = x^2$, $t \geq 0$.

$t^2 + 4t - 5 = 0 \Rightarrow t_1 = 1$, $t_2 = -5$ (відкидаємо).

$x^2 = 1 \Rightarrow x = \pm 1$ — два корені.

Відповідь: $2$.

3. Скільки коренів має рівняння $x^4 + x^2 + 1 = 0$?

4. Розв'яжіть рівняння: $x^4 - 6x^2 + 9 = 0$. Знайдіть суму коренів.

Розв'язання:

Заміна: $t = x^2$, $t \geq 0$.

$t^2 - 6t + 9 = 0 \Rightarrow (t - 3)^2 = 0 \Rightarrow t = 3$.

$x^2 = 3 \Rightarrow x = \pm\sqrt{3}$.

Сума: $\sqrt{3} + (-\sqrt{3}) = 0$.

Відповідь: $0$.

5. Розв'яжіть рівняння: $(x^2 - 3x)^2 - 2(x^2 - 3x) - 8 = 0$

6. Розв'яжіть рівняння: $\dfrac{1}{x^2} - \dfrac{3}{x} + 2 = 0$. У відповідь запишіть суму коренів.

Розв'язання:

ОДЗ: $x \neq 0$. Заміна: $t = \dfrac{1}{x}$.

$t^2 - 3t + 2 = 0 \Rightarrow t_1 = 1$, $t_2 = 2$.

$x_1 = 1$, $x_2 = \dfrac{1}{2}$.

Сума: $1 + \dfrac{1}{2} = \dfrac{3}{2}$.

Відповідь: $\dfrac{3}{2}$.

7. Розв'яжіть рівняння: $x + \sqrt{x} - 6 = 0$

8. Розв'яжіть рівняння: $\sqrt{x} - 3\sqrt[4]{x} + 2 = 0$. Знайдіть добуток коренів.

9. Розв'яжіть рівняння: $x^4 - 13x^2 + 36 = 0$. Знайдіть суму коренів.

Розв'язання:

Заміна: $t = x^2$, $t \geq 0$.

$t^2 - 13t + 36 = 0 \Rightarrow t_1 = 4$, $t_2 = 9$.

Корені: $x = \pm 2, \pm 3$.

Сума: $2 + (-2) + 3 + (-3) = 0$.

Відповідь: $0$.

10. Розв'яжіть рівняння: $(x^2 + x - 1)(x^2 + x + 2) = 40$. У відповідь запишіть більший корінь.

Розв'язання:

Заміна: $t = x^2 + x$.

$(t - 1)(t + 2) = 40 \Rightarrow t^2 + t - 42 = 0$.

$t_1 = 6$, $t_2 = -7$.

$x^2 + x = 6 \Rightarrow x^2 + x - 6 = 0 \Rightarrow x_1 = 2$, $x_2 = -3$.

$x^2 + x = -7$ — коренів немає.

Більший корінь: $2$.

Відповідь: $2$.
