Лінійні, квадратні, дробово-раціональні рівняння; рівняння з модулем

Мета заняття

Систематизувати та узагальнити знання учнів про основні типи рівнянь, що трапляються у завданнях НМТ: лінійні, квадратні, дробово-раціональні рівняння та рівняння, що містять знак модуля. Сформувати уміння визначати тип рівняння, обирати раціональний спосіб його розв'язування, враховувати обмеження області допустимих значень (ОДЗ), виконувати перевірку коренів та відсіювати сторонні корені.

Теоретична довідка

1. Лінійні рівняння

Лінійним називають рівняння виду

$ax + b = 0$, де $a$ і $b$ — дані числа (коефіцієнти), а $x$ — невідоме.

Залежно від значень коефіцієнтів можливі три випадки:

  1. якщо $a \neq 0$ — рівняння має єдиний корінь $x = -\dfrac{b}{a}$;
  2. якщо $a = 0,\ b \neq 0$ — рівняння коренів не має (набуває вигляду $0=b$, що хибно);
  3. якщо $a = 0,\ b = 0$ — коренем є будь-яке число (рівняння $0=0$ істинне завжди).

До лінійних також зводяться рівняння, що містять розкриття дужок, зведення подібних доданків і перенесення невідомих в одну частину рівняння.

Приклад 1

Розв'яжіть рівняння: $3(x - 2) = 5x + 4$.

Розв'язання:

Розкриємо дужки: $3x - 6 = 5x + 4$.
Перенесемо доданки з $x$ в один бік, числа — в інший:
$3x - 5x = 4 + 6$
$-2x = 10$
$x = -5$.

Відповідь: $x = -5$.

2. Квадратні рівняння

Квадратним називають рівняння виду $ax^2 + bx + c = 0$, де $a \neq 0$. Кількість і вигляд коренів визначає дискримінант:

$D = b^2 - 4ac$

  • якщо $D > 0$ — два різних корені: $x_{1,2} = \dfrac{-b \pm \sqrt{D}}{2a}$;
  • якщо $D = 0$ — один (подвійний) корінь: $x = -\dfrac{b}{2a}$;
  • якщо $D < 0$ — дійсних коренів немає.

Теорема Вієта: якщо $x_1$ і $x_2$ — корені зведеного квадратного рівняння $x^2 + px + q = 0$, то $x_1 + x_2 = -p$ та $x_1 \cdot x_2 = q$. Для рівняння загального вигляду $ax^2+bx+c=0$: $x_1+x_2 = -\dfrac{b}{a}$, $x_1 x_2 = \dfrac{c}{a}$.

Неповні квадратні рівняння розв'язують без формули дискримінанта: $ax^2 + c = 0 \Rightarrow x = \pm\sqrt{-\dfrac{c}{a}}$ (якщо $-\dfrac{c}{a}\ge 0$); $ax^2 + bx = 0 \Rightarrow x(ax+b)=0 \Rightarrow x=0$ або $x=-\dfrac{b}{a}$.

Приклад 2

Розв'яжіть рівняння: $2x^2 - 5x - 3 = 0$.

Розв'язання:

Тут $a=2,\ b=-5,\ c=-3$.
$D = (-5)^2 - 4\cdot 2\cdot(-3) = 25 + 24 = 49$.
$\sqrt{D} = 7$.
$x_{1,2} = \dfrac{5 \pm 7}{4}$, тобто $x_1 = \dfrac{12}{4} = 3$, $x_2 = \dfrac{-2}{4} = -0{,}5$.

Відповідь: $x_1 = 3$, $x_2 = -0{,}5$.

3. Дробово-раціональні рівняння

Дробово-раціональним називають рівняння, в якому невідома змінна міститься у знаменнику хоча б одного дробу. Алгоритм розв'язування:

  1. Знайти ОДЗ — значення змінної, за яких усі знаменники не дорівнюють нулю.
  2. Звести всі доданки до спільного знаменника й прирівняти чисельник до нуля.
  3. Розв'язати здобуте рівняння (лінійне або квадратне).
  4. Перевірити знайдені корені на відповідність ОДЗ; корені, що не входять в ОДЗ, є сторонніми і відкидаються.
Приклад 3

Розв'яжіть рівняння: $\dfrac{2x}{x-1} = \dfrac{4}{x-1} + 1$.

Розв'язання:

ОДЗ: $x - 1 \neq 0 \Rightarrow x \neq 1$.
Перенесемо всі доданки в одну частину та зведемо до спільного знаменника:
$\dfrac{2x}{x-1} - \dfrac{4}{x-1} - 1 = 0 \ \Rightarrow\ \dfrac{2x - 4 - (x-1)}{x-1} = 0$
$\dfrac{x - 3}{x-1} = 0$.
Дріб дорівнює нулю, коли чисельник дорівнює нулю (а знаменник — ні):
$x - 3 = 0 \Rightarrow x = 3$.
$x = 3$ входить в ОДЗ ($3 \neq 1$), отже це не сторонній корінь.

Відповідь: $x = 3$.

4. Рівняння з модулем

Модулем числа $a$ називають його відстань до нуля на координатній прямій: $|a| = a$, якщо $a \ge 0$, і $|a| = -a$, якщо $a < 0$. Звідси випливають основні прийоми розв'язування рівнянь з модулем.

Найпростіше рівняння $|f(x)| = a$:

  • якщо $a < 0$ — коренів немає;
  • якщо $a = 0$ — розв'язуємо $f(x) = 0$;
  • якщо $a > 0$ — рівняння рівносильне сукупності $f(x) = a$ або $f(x) = -a$.

Рівняння виду $|f(x)| = g(x)$ рівносильне системі: $f(x) = g(x)$ або $f(x) = -g(x)$, за умови $g(x) \ge 0$ (цю умову зручно перевірити безпосередньою підстановкою знайдених коренів).

Рівняння виду $|f(x)| = |g(x)|$ рівносильне сукупності $f(x) = g(x)$ або $f(x) = -g(x)$ (без додаткових умов на знак).

Приклад 4

Розв'яжіть рівняння: $|2x - 1| = 5$.

Розв'язання:

Оскільки $5 > 0$, маємо сукупність:
$2x - 1 = 5$ або $2x - 1 = -5$.
З першого рівняння: $2x = 6 \Rightarrow x = 3$.
З другого: $2x = -4 \Rightarrow x = -2$.

Відповідь: $x_1 = 3$, $x_2 = -2$.

Приклад 5

Розв'яжіть рівняння: $|x - 3| = 2x - 1$.

Розв'язання:

Права частина має бути невід'ємною: $2x - 1 \ge 0 \Rightarrow x \ge 0{,}5$.
Розглядаємо сукупність:
1) $x - 3 = 2x - 1 \Rightarrow -x = 2 \Rightarrow x = -2$ — не задовольняє умову $x \ge 0{,}5$, тому стороннє;
2) $x - 3 = -(2x - 1) \Rightarrow x - 3 = -2x + 1 \Rightarrow 3x = 4 \Rightarrow x = \dfrac{4}{3}$ — задовольняє умову.

Відповідь: $x = \dfrac{4}{3}$.

📝 Перевірте себе

1. Розв'яжіть рівняння $4x - 7 = 2x + 9$.

2. Знайдіть суму коренів рівняння $x^2 - 5x + 6 = 0$. У відповідь запишіть число.

3. Скільки коренів має рівняння $D<0$ для квадратного рівняння з дійсними коефіцієнтами?

4. Розв'яжіть рівняння $\dfrac{3x}{x+2} = \dfrac{6}{x+2} + 1$. У відповідь запишіть корінь.

Розв'язання:

ОДЗ: $x \neq -2$.
$\dfrac{3x}{x+2} - \dfrac{6}{x+2} - 1 = 0 \Rightarrow \dfrac{3x - 6 - (x+2)}{x+2} = 0 \Rightarrow \dfrac{2x - 8}{x+2} = 0$.
$2x - 8 = 0 \Rightarrow x = 4$. Оскільки $4 \neq -2$, корінь входить в ОДЗ.

5. Скільки коренів має рівняння $|x + 2| = -3$?

6. Розв'яжіть рівняння $|3x - 6| = 9$. У відповідь запишіть суму коренів.

Розв'язання:

Оскільки $9 > 0$: $3x - 6 = 9$ або $3x - 6 = -9$.
$3x = 15 \Rightarrow x_1 = 5$.
$3x = -3 \Rightarrow x_2 = -1$.
Сума коренів: $5 + (-1) = 4$.
