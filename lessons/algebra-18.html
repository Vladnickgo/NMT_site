Тригонометрія. Одиничне коло. Тотожності. Формули зведення. Рівняння

Мета заняття

Повторити означення тригонометричних функцій, одиничне коло, основні тригонометричні тотожності, формули зведення. Навчитися розв'язувати найпростіші тригонометричні рівняння та застосовувати формули додавання й подвійного кута. Підготуватися до виконання завдань НМТ.

1. Означення тригонометричних функцій

Розглянемо одиничне коло — коло радіуса 1 з центром у початку координат. Нехай точка $P(x; y)$ лежить на цьому колі, а $\alpha$ — кут між додатним напрямом осі $Ox$ і променем $OP$.

Означення тригонометричних функцій:

  • $\sin \alpha = y$ (ордината точки $P$)
  • $\cos \alpha = x$ (абсциса точки $P$)
  • $\text{tg}\, \alpha = \dfrac{y}{x} = \dfrac{\sin \alpha}{\cos \alpha}$, при $\cos \alpha \neq 0$
  • $\text{ctg}\, \alpha = \dfrac{x}{y} = \dfrac{\cos \alpha}{\sin \alpha}$, при $\sin \alpha \neq 0$

2. Знаки тригонометричних функцій у чвертях

Функція I II III IV
$\sin \alpha$ + + − −
$\cos \alpha$ + − − +
$\text{tg}$, $\text{ctg}$ + − + −
💡
Мнемонічне правило: «У I чверті — усі додатні. У II — тільки sin. У III — тільки tg і ctg. У IV — тільки cos».

$\sin \alpha$ $0$ $\dfrac{1}{2}$ $\dfrac{\sqrt{2}}{2}$ $\dfrac{\sqrt{3}}{2}$ $1$

4. Основні тригонометричні тотожності

Основна тригонометрична тотожність:

$$\sin^2 \alpha + \cos^2 \alpha = 1$$

Наслідки:

  • $\text{tg}\, \alpha = \dfrac{\sin \alpha}{\cos \alpha}$
  • $\text{ctg}\, \alpha = \dfrac{\cos \alpha}{\sin \alpha}$
  • $\text{tg}\, \alpha \cdot \text{ctg}\, \alpha = 1$
  • $1 + \text{tg}^2\, \alpha = \dfrac{1}{\cos^2 \alpha}$
  • $1 + \text{ctg}^2\, \alpha = \dfrac{1}{\sin^2 \alpha}$

Формули додавання

  • $\sin(\alpha + \beta) = \sin\alpha \cos\beta + \cos\alpha \sin\beta$
  • $\sin(\alpha - \beta) = \sin\alpha \cos\beta - \cos\alpha \sin\beta$
  • $\cos(\alpha + \beta) = \cos\alpha \cos\beta - \sin\alpha \sin\beta$
  • $\cos(\alpha - \beta) = \cos\alpha \cos\beta + \sin\alpha \sin\beta$

Формули подвійного кута

  • $\sin 2\alpha = 2\sin\alpha \cos\alpha$

  • $\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = $
    $ = 1 - 2\sin^2\alpha = 2\cos^2\alpha - 1$

5. Формули зведення

Формули зведення дозволяють виразити тригонометричні функції кутів виду $90° \pm \alpha$, $180° \pm \alpha$, $270° \pm \alpha$, $360° \pm \alpha$ через функції кута $\alpha$.

💡
Правило:
  • Якщо кут відкладається від горизонтальної осі ($180° \pm \alpha$, $360° \pm \alpha$, $-\alpha$) — функція зберігається.
  • Якщо кут відкладається від вертикальної осі ($90° \pm \alpha$, $270° \pm \alpha$) — функція змінюється на кофункцію (sin ↔ cos, tg ↔ ctg).
  • Знак визначається за знаком початкової функції в тій чверті, де знаходиться кут.

Приклади:

  • $\sin(180° - \alpha) = \sin\alpha$
  • $\cos(180° - \alpha) = -\cos\alpha$
  • $\sin(90° - \alpha) = \cos\alpha$
  • $\cos(90° + \alpha) = -\sin\alpha$
  • $\sin(180° + \alpha) = -\sin\alpha$

6. Найпростіші тригонометричні рівняння

  • $\sin x = a$, $|a| \leq 1$: $x = (-1)^n \arcsin a + \pi n$, $n \in \mathbb{Z}$.
  • $\cos x = a$, $|a| \leq 1$: $x = \pm \arccos a + 2\pi n$, $n \in \mathbb{Z}$.
  • $\text{tg}\, x = a$: $x = \text{arctg}\, a + \pi n$, $n \in \mathbb{Z}$.

Окремі випадки:

  • $\sin x = 0 \Rightarrow x = \pi n$
  • $\sin x = 1 \Rightarrow x = \dfrac{\pi}{2} + 2\pi n$
  • $\sin x = -1 \Rightarrow x = -\dfrac{\pi}{2} + 2\pi n$
  • $\cos x = 0 \Rightarrow x = \dfrac{\pi}{2} + \pi n$
  • $\cos x = 1 \Rightarrow x = 2\pi n$
  • $\cos x = -1 \Rightarrow x = \pi + 2\pi n$
Приклад 1. Знайти значення виразу

Обчисліть: $\sin 30° + \cos 60°$

Розв'язання:

$\sin 30° = \dfrac{1}{2}$, $\cos 60° = \dfrac{1}{2}$.

$\dfrac{1}{2} + \dfrac{1}{2} = 1$.

Відповідь: $1$.

Приклад 2. Основна тотожність

Знайдіть $\cos\alpha$, якщо $\sin\alpha = \dfrac{3}{5}$ і $\alpha$ — кут I чверті.

Розв'язання:

$\sin^2\alpha + \cos^2\alpha = 1 \Rightarrow \cos^2\alpha = 1 - \dfrac{9}{25} = \dfrac{16}{25}$.

$\cos\alpha = \dfrac{4}{5}$ (бо I чверть — косинус додатний).

Відповідь: $\dfrac{4}{5} = 0{,}8$.

Приклад 3. Формули зведення

Обчисліть: $\sin 150°$

Розв'язання:

$150° = 180° - 30°$. За формулою зведення:

$\sin 150° = \sin(180° - 30°) = \sin 30° = \dfrac{1}{2}$.

Відповідь: $\dfrac{1}{2}$.

Приклад 4. Формули зведення

Обчисліть: $\cos 120°$

Розв'язання:

$120° = 180° - 60°$.

$\cos 120° = \cos(180° - 60°) = -\cos 60° = -\dfrac{1}{2}$.

Відповідь: $-\dfrac{1}{2}$.

Приклад 5. Подвійний кут

Обчисліть: $\sin 2\alpha$, якщо $\sin\alpha = \dfrac{1}{3}$ і $\cos\alpha = \dfrac{2\sqrt{2}}{3}$.

Розв'язання:

$\sin 2\alpha = 2\sin\alpha \cos\alpha = 2 \cdot \dfrac{1}{3} \cdot \dfrac{2\sqrt{2}}{3} = \dfrac{4\sqrt{2}}{9}$.

Відповідь: $\dfrac{4\sqrt{2}}{9}$.

Приклад 6. Спрощення

Спростіть: $\dfrac{\sin^2\alpha}{1 - \cos^2\alpha}$

Розв'язання:

$1 - \cos^2\alpha = \sin^2\alpha$.

$\dfrac{\sin^2\alpha}{\sin^2\alpha} = 1$, при $\sin\alpha \neq 0$.

Відповідь: $1$.

Приклад 7. Тригонометричне рівняння

Розв'яжіть: $\sin x = \dfrac{1}{2}$

Розв'язання:

$\arcsin \dfrac{1}{2} = \dfrac{\pi}{6}$.

$x = (-1)^n \cdot \dfrac{\pi}{6} + \pi n$, $n \in \mathbb{Z}$.

Або у градусах: $x = 30° + 360°n$ або $x = 150° + 360°n$.

Відповідь: $x = (-1)^n \dfrac{\pi}{6} + \pi n$, $n \in \mathbb{Z}$.

Приклад 8. Рівняння з косинусом

Розв'яжіть: $\cos x = \dfrac{\sqrt{2}}{2}$

Розв'язання:

$\arccos \dfrac{\sqrt{2}}{2} = \dfrac{\pi}{4}$.

$x = \pm \dfrac{\pi}{4} + 2\pi n$, $n \in \mathbb{Z}$.

Відповідь: $x = \pm \dfrac{\pi}{4} + 2\pi n$, $n \in \mathbb{Z}$.

Приклад 9. Рівняння з тангенсом

Розв'яжіть: $\text{tg}\, x = 1$

Розв'язання:

$\text{arctg}\, 1 = \dfrac{\pi}{4}$.

$x = \dfrac{\pi}{4} + \pi n$, $n \in \mathbb{Z}$.

Відповідь: $x = \dfrac{\pi}{4} + \pi n$, $n \in \mathbb{Z}$.

Приклад 10. Обчислення через формули зведення

Обчисліть: $\sin 135° \cdot \cos 45°$

Розв'язання:

$\sin 135° = \sin(180° - 45°) = \sin 45° = \dfrac{\sqrt{2}}{2}$.

$\cos 45° = \dfrac{\sqrt{2}}{2}$.

$\dfrac{\sqrt{2}}{2} \cdot \dfrac{\sqrt{2}}{2} = \dfrac{2}{4} = \dfrac{1}{2}$.

Відповідь: $\dfrac{1}{2}$.

7. Завдання з НМТ

НМТ. Обчислення значення

Обчисліть: $2\sin 30° - 3\cos 60° + \text{tg}\, 45°$

Розв'язання:

$\sin 30° = \dfrac{1}{2}$, $\cos 60° = \dfrac{1}{2}$, $\text{tg}\, 45° = 1$.

$2 \cdot \dfrac{1}{2} - 3 \cdot \dfrac{1}{2} + 1 = 1 - \dfrac{3}{2} + 1 = 2 - 1{,}5 = 0{,}5$.

Відповідь: $0{,}5$.

НМТ. Знайти значення виразу

Обчисліть: $\sin^2 40° + \cos^2 40° + \sin 30°$

Розв'язання:

$\sin^2 40° + \cos^2 40° = 1$.

$1 + \dfrac{1}{2} = 1{,}5$.

Відповідь: $1{,}5$.

НМТ. Обчислити косинус

Знайдіть $\cos\alpha$, якщо $\sin\alpha = 0{,}6$ і $\dfrac{\pi}{2} < \alpha < \pi$.

Розв'язання:

$\cos^2\alpha = 1 - 0{,}36 = 0{,}64 \Rightarrow \cos\alpha = \pm 0{,}8$.

Оскільки $\alpha$ — II чверть, $\cos\alpha < 0$.

$\cos\alpha = -0{,}8$.

Відповідь: $-0{,}8$.

НМТ. Подвійний кут

Обчисліть: $\cos 2\alpha$, якщо $\cos\alpha = \dfrac{1}{3}$.

Розв'язання:

$\cos 2\alpha = 2\cos^2\alpha - 1 = 2 \cdot \dfrac{1}{9} - 1 = \dfrac{2}{9} - 1 = -\dfrac{7}{9}$.

Відповідь: $-\dfrac{7}{9}$.
