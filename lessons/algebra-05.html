Дробово-раціональні вирази та дії з ними

Мета заняття

Повторити поняття дробово-раціонального виразу, навчитися знаходити його ОДЗ, скорочувати дроби, виконувати додавання, віднімання, множення та ділення дробово-раціональних виразів.

1. Дробово-раціональні вирази

Раціональний вираз — це вираз, складений зі чисел і змінних за допомогою дій додавання, віднімання, множення, піднесення до степеня з натуральним показником та ділення на вираз зі змінною (або без нього).

Дробово-раціональний вираз — це дріб, чисельник і знаменник якого — многочлени. Наприклад:

$$\dfrac{x + 3}{x - 2}, \qquad \dfrac{x^2 - 1}{x^2 + 4x + 4}, \qquad \dfrac{5}{a^2 + b^2}$$

Область допустимих значень (ОДЗ)

Дріб має зміст тоді і тільки тоді, коли його знаменник не дорівнює нулю.

Щоб знайти ОДЗ дробово-раціонального виразу, треба:

  1. Прирівняти знаменник (або кожен знаменник, якщо їх декілька) до нуля.
  2. Розв'язати отримане рівняння.
  3. Виключити знайдені значення змінної з множини всіх дійсних чисел.
Приклад 1. Знаходження ОДЗ

Знайдіть ОДЗ виразу: $\dfrac{x + 5}{x - 3}$

Розв'язання:

Знаменник дорівнює нулю при $x - 3 = 0$, тобто $x = 3$.

Отже, ОДЗ: $x \neq 3$, або $x \in (-\infty; 3) \cup (3; +\infty)$.

Відповідь: $x \neq 3$.

Приклад 2. ОДЗ із квадратним тричленом

Знайдіть ОДЗ виразу: $\dfrac{2x}{x^2 - 9}$

Розв'язання:

$x^2 - 9 = 0 \Rightarrow (x - 3)(x + 3) = 0 \Rightarrow x = 3$ або $x = -3$.

Точки $x = 3$ та $x=-3$ виколоті — тут знаменник дорівнює нулю

Відповідь: $x \neq 3$ і $x \neq -3$.

2. Скорочення дробово-раціональних виразів

Скоротити дріб — означає поділити чисельник і знаменник на їх спільний множник. Для цього треба розкласти і чисельник, і знаменник на множники та скоротити однакові.

Основна властивість дробу:

$$\dfrac{a \cdot c}{b \cdot c} = \dfrac{a}{b}, \qquad b \neq 0, \; c \neq 0$$

Приклад 3. Скорочення дробу

Скоротіть дріб: $\dfrac{x^2 - 9}{x^2 + 6x + 9}$

Розв'язання:

Розкладемо чисельник і знаменник на множники:

$x^2 - 9 = (x - 3)(x + 3)$ — різниця квадратів.

$x^2 + 6x + 9 = (x + 3)^2$ — квадрат суми.

Тоді:

$$\dfrac{x^2 - 9}{x^2 + 6x + 9} = \dfrac{(x - 3)(x + 3)}{(x + 3)^2} = \dfrac{x - 3}{x + 3}$$

Відповідь: $\dfrac{x - 3}{x + 3}$, при $x \neq -3$.

Приклад 4. Скорочення з винесенням спільного множника

Скоротіть дріб: $\dfrac{3x^2 + 6x}{x^2 + 4x + 4}$

Розв'язання:

Чисельник: $3x^2 + 6x = 3x(x + 2)$.

Знаменник: $x^2 + 4x + 4 = (x + 2)^2$.

$$\dfrac{3x(x + 2)}{(x + 2)^2} = \dfrac{3x}{x + 2}$$

Відповідь: $\dfrac{3x}{x + 2}$, при $x \neq -2$.

3. Додавання та віднімання дробів

З однаковими знаменниками

$$\dfrac{a}{c} + \dfrac{b}{c} = \dfrac{a + b}{c}, \qquad \dfrac{a}{c} - \dfrac{b}{c} = \dfrac{a - b}{c}$$

З різними знаменниками

Зводимо до спільного знаменника (найкраще — до найменшого спільного):

$$\dfrac{a}{b} + \dfrac{c}{d} = \dfrac{a \cdot d + c \cdot b}{b \cdot d}$$

Приклад 5. Додавання з різними знаменниками

Обчисліть: $\dfrac{3}{x} + \dfrac{2}{x + 1}$

Розв'язання:

Спільний знаменник: $x(x + 1)$.

$$\dfrac{3(x + 1)}{x(x + 1)} + \dfrac{2x}{x(x + 1)} = \dfrac{3x + 3 + 2x}{x(x + 1)} = \dfrac{5x + 3}{x(x + 1)}$$

Відповідь: $\dfrac{5x + 3}{x(x + 1)}$, при $x \neq 0$, $x \neq -1$.

Приклад 6. Віднімання дробів

Обчисліть: $\dfrac{5}{x - 2} - \dfrac{3}{x + 2}$

Розв'язання:

Спільний знаменник: $(x - 2)(x + 2) = x^2 - 4$.

$$\dfrac{5(x + 2) - 3(x - 2)}{(x - 2)(x + 2)} = \dfrac{5x + 10 - 3x + 6}{x^2 - 4} = \dfrac{2x + 16}{x^2 - 4}$$

Відповідь: $\dfrac{2x + 16}{x^2 - 4}$, при $x \neq \pm 2$.

4. Множення та ділення дробів

Множення: чисельник на чисельник, знаменник на знаменник:

$$\dfrac{a}{b} \cdot \dfrac{c}{d} = \dfrac{a \cdot c}{b \cdot d}$$

Ділення: множимо на «перевернутий» дріб:

$$\dfrac{a}{b} : \dfrac{c}{d} = \dfrac{a}{b} \cdot \dfrac{d}{c} = \dfrac{a \cdot d}{b \cdot c}, \qquad c \neq 0$$

Приклад 7. Множення дробів

Обчисліть: $\dfrac{x + 1}{x - 1} \cdot \dfrac{x^2 - 1}{x^2 + 2x + 1}$

Розв'язання:

Розкладемо на множники:

$x^2 - 1 = (x - 1)(x + 1)$

$x^2 + 2x + 1 = (x + 1)^2$

$$\dfrac{x + 1}{x - 1} \cdot \dfrac{(x - 1)(x + 1)}{(x + 1)^2} = \dfrac{(x + 1)^2 (x - 1)}{(x - 1)(x + 1)^2} = 1$$

Відповідь: $1$, при $x \neq \pm 1$.

Приклад 8. Ділення дробів

Обчисліть: $\dfrac{x}{x + 3} : \dfrac{x^2}{x^2 - 9}$

Розв'язання:

Перевертаємо другий дріб і множимо:

$$\dfrac{x}{x + 3} \cdot \dfrac{x^2 - 9}{x^2} = \dfrac{x \cdot (x - 3)(x + 3)}{(x + 3) \cdot x^2}$$

Скорочуємо $(x + 3)$ та $x$:

$$= \dfrac{x - 3}{x}$$

Відповідь: $\dfrac{x - 3}{x}$, при $x \neq 0, \pm 3$.

5. Спрощення складних дробово-раціональних виразів

Для спрощення складних виразів використовують порядок дій:

  1. Дії в дужках.
  2. Множення і ділення.
  3. Додавання і віднімання.
Приклад 9. Спрощення складного виразу

Спростіть вираз: $\left(\dfrac{1}{a} + \dfrac{1}{b}\right) \cdot \dfrac{ab}{a + b}$

Розв'язання:

Спочатку виконаємо дію в дужках:

$$\dfrac{1}{a} + \dfrac{1}{b} = \dfrac{b + a}{ab}$$

Тепер множимо:

$$\dfrac{a + b}{ab} \cdot \dfrac{ab}{a + b} = 1$$

Відповідь: $1$, при $a \neq 0, b \neq 0, a \neq -b$.

Приклад 10. Спрощення виразу з дужками

Спростіть вираз: $\dfrac{x^2 - 4}{x + 3} \cdot \left(1 - \dfrac{1}{x + 2}\right)$

Розв'язання:

Спростимо вираз у дужках:

$$1 - \dfrac{1}{x + 2} = \dfrac{(x + 2) - 1}{x + 2} = \dfrac{x + 1}{x + 2}$$

Тепер множимо:

$$\dfrac{(x - 2)(x + 2)}{x + 3} \cdot \dfrac{x + 1}{x + 2} = \dfrac{(x - 2)(x + 1)}{x + 3}$$

Відповідь: $\dfrac{(x - 2)(x + 1)}{x + 3}$, при $x \neq -3, -2$.

📝 Перевірте себе

1. Знайдіть ОДЗ виразу: $\dfrac{5}{x - 7}$

2. Знайдіть ОДЗ виразу: $\dfrac{3x}{x^2 - 16}$

3. Скоротіть дріб: $\dfrac{x^2 - 4}{x + 2}$

Розв'язання:

$x^2 - 4 = (x - 2)(x + 2)$

$\dfrac{(x - 2)(x + 2)}{x + 2} = x - 2$

Відповідь: $x - 2$, при $x \neq -2$.

4. Скоротіть дріб: $\dfrac{x^2 + 6x + 9}{x + 3}$

5. Обчисліть: $\dfrac{2}{x} + \dfrac{3}{x}$

6. Обчисліть: $\dfrac{1}{x - 1} - \dfrac{1}{x + 1}$

7. Обчисліть: $\dfrac{x}{x + 2} \cdot \dfrac{x + 2}{x^2}$

Розв'язання:

$\dfrac{x}{x + 2} \cdot \dfrac{x + 2}{x^2} = \dfrac{x \cdot (x + 2)}{(x + 2) \cdot x^2} = \dfrac{1}{x}$

Відповідь: $\dfrac{1}{x}$, при $x \neq 0, -2$.

8. Обчисліть: $\dfrac{x^2}{x - 3} : \dfrac{x}{x - 3}$

9. Спростіть вираз: $\left(\dfrac{1}{a} - \dfrac{1}{b}\right) \cdot \dfrac{ab}{b - a}$

Розв'язання:

$\dfrac{1}{a} - \dfrac{1}{b} = \dfrac{b - a}{ab}$

$\dfrac{b - a}{ab} \cdot \dfrac{ab}{b - a} = 1$

Чекайте — тут знак: $\dfrac{1}{a} - \dfrac{1}{b} = \dfrac{b - a}{ab}$, а множимо на $\dfrac{ab}{b - a}$.

$\dfrac{b - a}{ab} \cdot \dfrac{ab}{b - a} = 1$.

Відповідь: $1$, при $a \neq 0, b \neq 0, a \neq b$.

10. Знайдіть значення виразу $\dfrac{x^2 - 1}{x + 1}$ при $x = 5$.
