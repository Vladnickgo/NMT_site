Похідна. Первісна. Типові задачі

Мета заняття

Повторити означення похідної, таблицю похідних, правила диференціювання, геометричний та фізичний зміст похідної. Ознайомитися з поняттям первісної та інтеграла. Навчитися розв'язувати типові задачі НМТ на похідну й первісну.

1. Означення похідної

Похідна функції $f(x)$ у точці $x_0$ — це границя відношення приросту функції до приросту аргументу, коли приріст аргументу прямує до нуля:

$$f'(x_0) = \lim_{\Delta x \to 0} \dfrac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$

Позначення похідної: $f'(x)$, $y'$, $\dfrac{dy}{dx}$.

Геометричний зміст похідної

$f'(x_0) = \text{tg}\, \alpha$ — кутовий коефіцієнт дотичної до графіка функції в точці $x_0$.

Рівняння дотичної:

$$y = f(x_0) + f'(x_0)(x - x_0)$$

Фізичний зміст похідної

Якщо $s(t)$ — шлях, то $s'(t) = v(t)$ — швидкість. А $v'(t) = a(t)$ — прискорення.

3. Правила диференціювання

  • $(u + v)' = u' + v'$ — похідна суми.
  • $(u \cdot v)' = u'v + uv'$ — похідна добутку.
  • $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$ — похідна частки.
  • $(C \cdot f)' = C \cdot f'$ — сталий множник.
  • $(f(g(x)))' = f'(g(x)) \cdot g'(x)$ — похідна складеної функції (ланцюгове правило).
💡
Ланцюгове правило — найважливіше при диференціюванні складених функцій. Наприклад: $(\sin(3x))' = \cos(3x) \cdot 3 = 3\cos(3x)$.
Приклад 1. Похідна многочлена

Знайдіть похідну функції $f(x) = 3x^4 - 2x^2 + 5x - 7$.

Розв'язання:

$f'(x) = 3 \cdot 4x^3 - 2 \cdot 2x + 5 - 0 = 12x^3 - 4x + 5$.

Відповідь: $f'(x) = 12x^3 - 4x + 5$.

Приклад 2. Похідна з коренем

Знайдіть похідну $f(x) = \sqrt{x} + \dfrac{1}{x}$.

Розв'язання:

$(\sqrt{x})' = \dfrac{1}{2\sqrt{x}}$, $\left(\dfrac{1}{x}\right)' = -\dfrac{1}{x^2}$.

$f'(x) = \dfrac{1}{2\sqrt{x}} - \dfrac{1}{x^2}$.

Відповідь: $f'(x) = \dfrac{1}{2\sqrt{x}} - \dfrac{1}{x^2}$.

Приклад 3. Похідна добутку

Знайдіть похідну $f(x) = x^2 \cdot \sin x$.

Розв'язання:

За правилом добутку: $(u \cdot v)' = u'v + uv'$.

$u = x^2$, $v = \sin x \Rightarrow u' = 2x$, $v' = \cos x$.

$f'(x) = 2x \sin x + x^2 \cos x$.

Відповідь: $f'(x) = 2x \sin x + x^2 \cos x$.

Приклад 4. Похідна частки

Знайдіть похідну $f(x) = \dfrac{x + 1}{x - 2}$.

Розв'язання:

$u = x + 1$, $v = x - 2 \Rightarrow u' = 1$, $v' = 1$.

$f'(x) = \dfrac{1 \cdot (x - 2) - (x + 1) \cdot 1}{(x - 2)^2} = \dfrac{x - 2 - x - 1}{(x - 2)^2} = \dfrac{-3}{(x - 2)^2}$.

Відповідь: $f'(x) = \dfrac{-3}{(x - 2)^2}$.

Приклад 5. Похідна складеної функції

Знайдіть похідну $f(x) = (2x + 3)^5$.

Розв'язання:

За ланцюговим правилом: $f'(x) = 5(2x + 3)^4 \cdot (2x + 3)' = 5(2x + 3)^4 \cdot 2 = 10(2x + 3)^4$.

Відповідь: $f'(x) = 10(2x + 3)^4$.

Приклад 6. Рівняння дотичної

Складіть рівняння дотичної до графіка функції $f(x) = x^2 - 3x + 1$ у точці $x_0 = 2$.

Розв'язання:

$f(x_0) = 4 - 6 + 1 = -1$.

$f'(x) = 2x - 3 \Rightarrow f'(2) = 4 - 3 = 1$.

Рівняння: $y = -1 + 1 \cdot (x - 2) = x - 3$.

Відповідь: $y = x - 3$.

Приклад 7. Кутовий коефіцієнт

Знайдіть кутовий коефіцієнт дотичної до графіка $f(x) = x^3 - 2x$ у точці $x_0 = 1$.

Розв'язання:

$f'(x) = 3x^2 - 2 \Rightarrow f'(1) = 3 - 2 = 1$.

Відповідь: $k = 1$.

4. Первісна та інтеграл

Первісна функції $f(x)$ — це така функція $F(x)$, похідна якої дорівнює $f(x)$:

$$F'(x) = f(x)$$

Первісна визначається з точністю до сталої: якщо $F(x)$ — первісна, то $F(x) + C$ — теж первісна.

Таблиця первісних

Функція $f(x)$ Первісна $F(x)$
$k$ (стала)$kx + C$
$x^n$, $n \neq -1$$\dfrac{x^{n+1}}{n+1} + C$
$\dfrac{1}{x}$$\ln|x| + C$
$\sin x$$-\cos x + C$
$\cos x$$\sin x + C$
$e^x$$e^x + C$

Формула Ньютона-Лейбніца

Для обчислення визначеного інтеграла:

$$\int_a^b f(x)\, dx = F(b) - F(a)$$

де $F(x)$ — первісна $f(x)$.

Приклад 8. Знайти первісну

Знайдіть первісну функції $f(x) = 3x^2$.

Розв'язання:

$F(x) = \dfrac{3x^3}{3} + C = x^3 + C$.

Перевірка: $(x^3)' = 3x^2$ ✅

Відповідь: $F(x) = x^3 + C$.

Приклад 9. Первісна з тригонометрії

Знайдіть первісну функції $f(x) = \cos x$.

Розв'язання:

$F(x) = \sin x + C$.

Перевірка: $(\sin x)' = \cos x$ ✅

Відповідь: $F(x) = \sin x + C$.

Приклад 10. Обчислення визначеного інтеграла

Обчисліть: $\displaystyle\int_1^3 2x\, dx$

Розв'язання:

$F(x) = x^2$.

$\displaystyle\int_1^3 2x\, dx = F(3) - F(1) = 9 - 1 = 8$.

Відповідь: $8$.

5. Застосування похідної: дослідження функції

  • Якщо $f'(x) > 0$ на проміжку — функція зростає.
  • Якщо $f'(x) < 0$ — функція спадає.
  • Точки, де $f'(x) = 0$ і похідна змінює знак, — точки екстремуму (максимум/мінімум).
Приклад 11. Точки екстремуму

Знайдіть точки екстремуму функції $f(x) = x^3 - 3x$.

Розв'язання:

$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x - 1)(x + 1)$.

$f'(x) = 0$ при $x = 1$ або $x = -1$.

Перевіримо знаки похідної:

  • $x < -1$: $f'(x) > 0$ — зростання.
  • $-1 < x < 1$: $f'(x) < 0$ — спадання.
  • $x > 1$: $f'(x) > 0$ — зростання.

$x = -1$ — точка максимуму, $x = 1$ — точка мінімуму.

Відповідь: $x_{max} = -1$, $x_{min} = 1$.

6. Завдання з НМТ

НМТ. Знайти похідну в точці

Знайдіть значення похідної функції $f(x) = x^2 + 3x$ у точці $x_0 = 2$.

Розв'язання:

$f'(x) = 2x + 3 \Rightarrow f'(2) = 4 + 3 = 7$.

Відповідь: $7$.

НМТ. Дотична

Знайдіть кутовий коефіцієнт дотичної до графіка $f(x) = x^2 - 4x + 5$ у точці $x_0 = 3$.

Розв'язання:

$f'(x) = 2x - 4 \Rightarrow f'(3) = 6 - 4 = 2$.

Відповідь: $k = 2$.

НМТ. Первісна

Для функції $f(x) = 2x$ знайдіть первісну $F(x)$, графік якої проходить через точку $(1; 3)$.

Розв'язання:

Загальний вигляд: $F(x) = x^2 + C$.

$F(1) = 3 \Rightarrow 1 + C = 3 \Rightarrow C = 2$.

$F(x) = x^2 + 2$.

Відповідь: $F(x) = x^2 + 2$.

НМТ. Обчислити інтеграл

Обчисліть: $\displaystyle\int_0^2 (3x^2 + 1)\, dx$

Розв'язання:

$F(x) = x^3 + x$.

$F(2) - F(0) = (8 + 2) - 0 = 10$.

Відповідь: $10$.

НМТ. Фізичний зміст

Тіло рухається за законом $s(t) = t^2 + 3t$. Знайдіть швидкість тіла в момент $t = 2$.

Розв'язання:

$v(t) = s'(t) = 2t + 3$.

$v(2) = 4 + 3 = 7$.

Відповідь: $v(2) = 7$ (од./с).
